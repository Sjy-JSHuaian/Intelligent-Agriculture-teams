# 算法说明（成员A）

> 目标：在丘陵梯田地形约束下，兼顾飞行安全、覆盖率、路径长度、任务优先级和模拟能耗，
> 完成多地块巡检。代码实现见 `src/planner/` 与 `src/simulator/`。

---

## 1. 问题定义

输入：

- 场景栅格：高程 $z$、坡度 $\theta$、障碍（建筑/树木/电线）硬掩膜、道路/沟渠软风险；
- 地块集合 $\{R_1,\dots,R_k\}$：多边形、风险 $r_i\in[0,1]$、优先级 $p_i\in\{1,2,3\}$；
- 无人机：巡航速度 $v=6$ m/s、爬升 $v_z=2$ m/s、离地高度 $h=25$ m、
  相机视场 $35^\circ$（地面幅面直径约 15.8 m）、电池 300 Wh、拍照悬停 2 s；
- 起降点 $q_0$。

输出：一条从 $q_0$ 出发、遍历所有地块、回到 $q_0$ 的航迹
$\tau=[(x,y,z,t,\text{field\_id},\text{action})]$，并满足：

1. 不穿越硬障碍、坡度 > 38° 的区域；
2. 每个地块都被相机幅面覆盖；
3. 电量满足 15% 余量（否则标记不可行）。

---

## 2. 基线算法（Baseline）

**固定顺序 + 固定航带 + 纯距离 A***：

1. 地块按编号 `T001…T0NN` 顺序访问（模拟“按调查表顺序飞”）。
2. 每块地按主方向（PCA 长轴）生成牛耕式航带，固定从西南角进入。
3. 地块之间用 8 邻域 A*，边代价 = 几何距离；只把硬障碍、陡坡、边界设为不可通行。
4. 不做风险排序、不做入口优化、不做坡度/安全/能耗代价。

基线的作用是“可复现的下界”，不是“最笨的算法”。

---

## 3. 改进算法（Improved）

### 3.1 地块排序：风险优先 + 最近邻

先按风险等级从高到低分组（high → medium → low），组内从当前位置选最近的地块质心。
这样保证高风险地块尽早被拍到，同时避免同等级内来回横跳。

评价指标用**风险加权完成时间**：

$$
J_{\text{lat}}=\frac{\sum_i (1+w_r r_i)\,t_i}{\sum_i (1+w_r r_i)},\qquad w_r=3
$$

其中 $t_i$ 是第 $i$ 块地首张照片的时间。$J_{\text{lat}}$ 越小，高风险任务越早完成。

### 3.2 覆盖航带与入口/出口优化（对应 mUDAI 的“视角优化”）

对每块地生成 4 个候选航带：

- 沿主方向 / 垂直主方向；
- 正向 / 反向。

每个候选的代价：

$$
c=\lVert e_{i-1}-a\rVert_2+\lVert b-c_{i+1}\rVert_2
$$

其中 $a$ 为入口、$b$ 为出口、$e_{i-1}$ 为上一块地出口、$c_{i+1}$ 为下一块地质心。
选代价最小的候选。这样在不增加覆盖次数的前提下，减少地块之间的空飞。

> 论文 mUDAI 用 dual-annealing 为每个 ROI 求一个最佳拍摄位姿（MCO/BCO），
> 再用 OR-Tools 解带电量约束的 VRP。我们的地块很小、需要多张照片，因此把
> “单视角”推广为“4 个航带变体”，把“VRP”推广为“风险分层 + 最近邻 + A* 转场”。
> 思想一致：**先定拍摄位置，再定访问顺序**；差异在求解器与单机约束。

### 3.3 转场 A*：地形/安全/能耗代价

代价面（每个栅格）：

$$
c_{\text{cell}}=1+w_s\left(\frac{\theta}{\theta_{\text{ref}}}\right)^2
+w_c\left[\frac{d_{\text{safe}}-d}{d_{\text{safe}}}\right]_{+}^{1.5}
+w_o\,s_{\text{soft}}
$$

边代价（从 $u$ 到 $v$）：

$$
c(u,v)=L_{uv}\cdot c_{\text{cell}}(v)+w_z\max(0,z_v-z_u)
$$

A* 启发式用八方向 octile 距离，保证可采纳（$c_{\text{cell}}\ge 1$）。

| 参数 | 值 | 含义 |
|---|---:|---|
| $w_s$ | 2.0 | 坡度惩罚权重 |
| $\theta_{\text{ref}}$ | 20° | 坡度归一化参考 |
| $w_c$ | 6.0 | 障碍安全距离惩罚 |
| $d_{\text{safe}}$ | 8 m | 进入该范围开始惩罚 |
| $w_o$ | 0.35 | 道路/沟渠软风险权重 |
| $w_z$ | 0.8 | 每米爬升代价 |
| 硬阻挡 | 障碍掩膜 或 $\theta>38^\circ$ | 不可通行 |
| 安全违规阈值 | 3 m | 统计用 |

路径后处理：视线法抽稀，但要求整段满足“不穿越障碍 + 改进模式距离障碍 ≥2.5 m”，
避免平滑时切角。

### 3.4 覆盖率与拍照

- 相机地面幅面半径 $r=h\tan(\text{FOV}/2)=7.88$ m；
- 航带间距 $s=2r(1-\text{overlap})=13.4$ m（overlap=15%）；
- 沿航向拍照间距 $0.65s\approx8.7$ m；
- 每张照片覆盖以拍照点为圆心、$r$ 为半径的栅格；地块覆盖率 = 被覆盖地块像元 / 地块像元。

### 3.5 能耗模型（一阶近似）

| 状态 | 功率 |
|---|---:|
| 平飞 | 180 W + 航电 25 W |
| 爬升 | 260 W + 航电 25 W |
| 悬停拍照 | 210 W + 航电 25 W |
| 下降 | 0.6×平飞 + 航电 |

$$
E=\sum \frac{P\,\Delta t}{3600}\ \text{(Wh)}
$$

电量约束：$E\le 300\times(1-0.15)=255$ Wh，否则 `battery_reserve_ok=false`。
复杂场景基线 314 Wh > 300 Wh，单架次不可完成；改进 220.6 Wh 可完成。

### 3.6 局部避障与重规划

1. 沿已规划航迹取 40%–45% 处的一个转场点；
2. 在航线侧向偏移 $0.55r_{\text{NFZ}}$ 生成圆形禁飞区（保证航线穿过圆、切点在圆外）；
3. 找到航迹第一次进入圆的点，回退一个航点作为切点；
4. 从切点开始，以“剩余地块 + 禁飞区掩膜”重新调用改进规划；
5. 若禁飞区压到地块，则该地块标记为跳过（计入 `skipped_fields`）；
6. 统计原航迹/新航迹在禁飞区内的长度。

结果：三个场景闯入长度 168.6/205.0/69.6 m → 0 m；简单场景因禁飞区压地跳过 1 块。

## 4. 计算复杂度

- 单次 A*：$O(N\log N)$，$N=n_x n_y$（简单 200²、中等 240²、复杂 280²）；
- 每个场景：$2k$ 次 A*（去/回），$k=12/22/34$；
- 覆盖航带：$O(k\cdot n_{\text{strips}}\cdot n_{\text{samples}})$，可忽略；
- 实测规划耗时：0.55–9.36 s（纯 Python，单线程），满足答辩演示。

## 5. 与论文 mUDAI 的对应关系

| mUDAI | 本项目 | 说明 |
|---|---|---|
| ROI 多边形 | 梯田地块多边形 | 数据规模更小、数量更多 |
| 单 ROI 最佳视角（dual annealing，MCO/BCO） | 4 种航带变体 + 入口/出口代价最小 | 地块需多张照片，不能只拍一张 |
| 多机 VRP（OR-Tools） | 单机风险分层 + 最近邻 + A* | 大创单机仿真，降低求解器依赖 |
| 电量约束拆分航线 | 300 Wh + 15% 余量判定 | 超限标记不可行，不强行拆分 |
| 多机高度层避碰 | 单机，无此问题 | 未来扩展点 |

## 6. 复现性

- 场景种子：`scene_simple=11`、`scene_medium=22`、`scene_complex=33`；
- 所有随机过程（地块、建筑、树木、风险）由 `numpy.random.default_rng(seed)` 驱动；
- A* 确定性；RRT* 未启用；
- 指标表由脚本自动写 CSV，不手填；
- 运行环境：Python 3.12，numpy 2.x，matplotlib 3.11（其他 3.10+ 亦可）。

---

## 7. 已知局限

1. 2.5D 规划：以 25 m AGL 定高飞行，未显式建模建筑/树木高度与三维避障；
2. 能耗为一阶功率模型，未标定真实机型；
3. 覆盖用圆形幅面近似，未考虑相机矩形画幅与姿态；
4. 单机、单架次；未实现多机任务分配与电量分段；
5. 地块/障碍物为仿真，结论只对仿真场景成立。
