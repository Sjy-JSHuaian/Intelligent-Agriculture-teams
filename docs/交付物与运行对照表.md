## ① 梯田仿真场景

**对应最低验收**：至少 3 种复杂度不同的场景；每个场景含地块边界、高程差异、障碍物配置。

- **代码**：`src/simulator/scene_builder.py`（构建）、`src/simulator/scene.py`（读取）
- **输入**：`../数据集存储/Copernicus_DEM_GLO30/raw/*.tif`、`../数据集存储/OpenStreetMap/raw/osm_yuanyang_core.json`
- **命令**：

```powershell
python scripts\01_build_scenes.py
# 只重建一个：python scripts\01_build_scenes.py --scenes scene_medium
```

- **屏幕预期输出**：

```
[OK] scene_simple: 12 fields, relief 162.5 m, hard 0.24%
[OK] scene_medium: 22 fields, relief 369.3 m, hard 0.41%
[OK] scene_complex: 34 fields, relief 630.5 m, hard 0.51%
```

- **生成文件**（每个场景一个文件夹）：

| 文件 | 内容 |
|---|---|
| `dem.tif` | 5 m 高程，EPSG:32648 |
| `slope.tif` / `aspect`（在 npz） | 坡度/坡向 |
| `field_id.tif` | 地块编号栅格（0=非地块） |
| `obstacle_mask.tif` | 建筑/树木/电线硬障碍 |
| `grid.npz` | 算法缓存（高程/坡度/坡向/粗糙度/障碍/地块/障碍距离） |
| `scene.json` | 地块列表、风险、起降点、来源说明、统计 |
| `fields.geojson/.shp` | 地块边界（含 `field_id/risk/level/priority`） |
| `boundary.*` | 场景边界 |
| `obstacles.geojson` + `buildings/trees/roads/ditches/powerlines.shp` | 障碍物 |
| `preview.png` | 快速检查图 |

- **验收证据**：`result/plot/fig1_scenes.png`；QGIS 打开 `dem.tif + fields.shp`。
- **注意**：真实 DEM + 人工地块/障碍物；`scene.json.sources/notes` 已逐项标注。

## ② 路径规划程序

**对应最低验收**：基线算法可运行；改进算法可运行；输入输出格式固定。

- **代码**：
  - `src/planner/astar.py`：A*、视线平滑、安全统计
  - `src/planner/costmap.py`：基线/改进代价面
  - `src/planner/coverage.py`：牛耕式覆盖航带、4 种入口变体
  - `src/planner/route.py`：地块排序、转场、时间/能耗、JSON 输出
- **命令**：

```powershell
python scripts\02_run_planning.py
# 只跑一个：python scripts\02_run_planning.py --scenes scene_medium --methods improved
```

- **屏幕预期输出**（每行一个场景/算法）：

```
[scene_simple/baseline] 12 块地, 航程 5021 m, 时间 1354 s, 能耗 79.8 Wh, 规划 1.4 s
[scene_simple/improved] 12 块地, 航程 4255 m, 时间 1187 s, 能耗 70.3 Wh, 规划 0.59 s
[scene_medium/baseline] 22 块地, 航程 9731 m, 时间 3105 s, 能耗 181.6 Wh, 规划 6.1 s
[scene_medium/improved] 22 块地, 航程 6459 m, 时间 2321 s, 能耗 136.5 Wh, 规划 3.8 s
[scene_complex/baseline] 34 块地, 航程 18502 m, 时间 5394 s, 能耗 314.1 Wh, 规划 14.2 s
[scene_complex/improved] 34 块地, 航程 11492 m, 时间 3758 s, 能耗 220.6 Wh, 规划 13.6 s
```

- **输出**：`result/traj/{scene}_{method}.json`，字段固定（`schema_version/scene/method/coords/uav/route/fields/waypoints/metrics`）。
- **怎么判断跑对了**：
  - 6 个 JSON 都有，`metrics.path_length_m` 与上表同量级；
  - `waypoints` 第一项 `action=takeoff`、最后一项 `action=land`；
  - `route` 含全部地块编号且不重复；
  - `metrics.coverage_pct` 由 03 回填（02 刚跑完是 `null`，正常）。

## ③ 巡检仿真结果

**对应最低验收**：可展示航迹、地块访问顺序、覆盖率和模拟能耗/距离。

- **代码**：`src/simulator/inspect.py`
- **命令**：

```powershell
python scripts\03_run_inspection.py
# 不生成占位图（更快）：python scripts\03_run_inspection.py --no-images
```

- **屏幕预期输出**：

```
[scene_medium/improved] 覆盖率 100.0% (地块均值 100.0%), 图像 192 张, 访问顺序 T018->T002->T015...
```

- **输出**：
  - `result/inspect/{scene}_{method}_inspection.json`：
    `visit_order`、逐地块 `coverage_pct`、`images[]` 图像索引、`totals`。
  - `result/inspect/{scene}_{method}_fields.csv`：逐地块表。
  - `result/inspect/images/{scene}/{method}/*.jpg`：仿真占位图（带 `SIMULATED` 水印）。
  - `result/inspect/{scene}_{method}_coverage.tif`：覆盖栅格，QGIS 可叠加。
- **图像数量**：140/147（简单）、209/192（中等）、300/308（复杂），合计 1296。
- **给成员B**：直接读 `images[]` 里的 `field_id / timestamp / path / x / y / z / gsd_cm`，
  图片本身是占位图，B 可用真实/渲染图按同名字段替换。
- **注意**：03 会把覆盖率回写进对应 traj JSON，所以 02 之后跑 03 是必要步骤。

## ④ 算法实验

**对应最低验收**：至少比较基线与改进；报告路径长度、覆盖率、规划时间、安全约束或碰撞次数。

- **代码**：`scripts/04_run_experiments.py`（批量）+ `src/simulator/replan.py`（禁飞区重规划）
- **命令**：

```powershell
python scripts\04_run_experiments.py
```

- **屏幕预期输出**：每个场景两行 + 一行重规划，最后写出两个 CSV。
- **输出**：
  - `result/experiment/metrics.csv`：20 列，6 行（3 场景 × 2 算法）。
  - `result/experiment/metrics.json`：同内容 JSON。
  - `result/experiment/replan.csv` / `replan.json`：禁飞区实验。
- **当前结果**（答辩可直接引用；规划耗时随机器负载波动，以 `metrics.csv` 为准）：

| 场景 | 算法 | 航程 m | 能耗 Wh | 电池占用 | 覆盖率 | 规划 s | 高风险平均次序 | 碰撞 |
|---|---|---:|---:|---:|---:|---:|---:|---:|
| 简单 | 基线 | 5021.0 | 79.79 | 26.6% | 100% | 1.4 | 5.75 | 0 |
| 简单 | 改进 | **4254.8** | **70.34** | 23.4% | 100% | 1.4 | **2.50** | 0 |
| 中等 | 基线 | 9730.9 | 181.62 | 60.5% | 100% | 6.1 | 14.71 | 1 |
| 中等 | 改进 | **6458.7** | **136.46** | 45.5% | 100% | 3.8 | **4.00** | **0** |
| 复杂 | 基线 | 18501.9 | 314.15 | **104.7%** | 100% | 14.2 | 13.73 | 0 |
| 复杂 | 改进 | **11491.7** | **220.64** | 73.5% | 100% | 13.6 | **6.00** | **0** |

- **结论口径**：
  1. 改进算法航程下降 15.3% / 33.6% / 37.9%，能耗下降 11.8% / 24.9% / 29.8%。
  2. 覆盖率均 100%：改进不是靠少拍地换航程。
  3. 高风险地块平均访问次序从 5.75/14.71/13.73 提前到 2.5/4.0/6.0。
  4. 复杂场景基线单架次电量不够（314 > 300 Wh），改进可完成；中等场景基线有 1 次碰撞，改进 0。
- **重规划**：原航迹闯入禁飞区 168.6/205.0/69.6 m，重规划后均为 **0 m**；简单场景跳过 1 块被禁飞区覆盖的地块。

## ⑤ 网页接口

**对应最低验收**：提供地图底图、航迹坐标、地块 ID 和覆盖信息。

- **代码**：`src/api/app.py`（FastAPI）+ `frontend/index.html`（Leaflet）
- **命令**：

```powershell
python scripts\06_serve_api.py
```

- **打开**：<http://127.0.0.1:8000/>；接口文档 <http://127.0.0.1:8000/docs>。
- **页面内容**：
  - 左上场景切换（简单/中等/复杂）、算法切换（基线/改进）；
  - 地形晕渲底图（由 DEM 生成，非在线瓦片，断网可用）；
  - 地块按风险着色，点击显示 `field_id/风险/优先级/面积/覆盖率`；
  - 航迹折线、拍照点；
  - 指标卡：航程/能耗/覆盖率/规划耗时/高风险次序/碰撞/电量。
- **接口**：见 `docs/接口文档.md`。
- **注意**：这是单用户演示，接口直接读本地 JSON，无数据库；不要用于多人并发生产环境。
