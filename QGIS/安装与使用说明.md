# QGIS 安装与使用（成员A）

> QGIS 是**软件**，不是数据集，因此本目录不存放 QGIS 安装包；请按官方渠道安装。

## 1. 下载安装

- 官网：<https://qgis.org/download/>
- 建议安装 **QGIS 3.34 LTR** 或更新版本（Windows 安装包约 1 GB）。
- 安装时保持默认组件即可（含 GDAL、PROJ）。

## 2. 打开本项目的场景

场景数据在 `project_A/data/scenes/scene_*/`，推荐按以下顺序加载：

| 文件 | 用途 | 建议样式 |
|---|---|---|
| `dem.tif` | 5 m 高程（EPSG:32648） | 单波段伪彩色 + 山体阴影 |
| `slope.tif` | 坡度（度） | 分级设色 0–10 / 10–20 / 20–30 / >30 |
| `field_id.tif` | 地块编号栅格 | 唯一值渲染，或只作参考 |
| `obstacle_mask.tif` | 建筑/树木/电线等硬障碍 | 红色半透明 |
| `fields.shp` | 地块边界（含风险/优先级字段） | 按 `level` 字段分级：low 绿 / medium 橙 / high 红 |
| `buildings.shp`、`trees.shp`、`roads.shp`、`ditches.shp`、`powerlines.shp` | 障碍物 | 建筑深灰、树木深绿、道路黄、沟渠蓝、电线红虚线 |
| `boundary.shp` | 场景边界 | 白色描边 |

操作要点：

1. `图层 → 添加图层 → 添加栅格图层`，选择 `dem.tif`；右下角确认 CRS 为 **EPSG:32648**。
2. 双击 DEM 图层 → `符号化` → `山体阴影`，或使用 `栅格 → 分析 → 山体阴影` 生成阴影图层叠加。
3. `添加矢量图层` 选择 `fields.shp`；`符号化 → 分类`，字段选 `level`。
4. 需要裁切时：`栅格 → 提取 → 按掩膜图层裁剪栅格`，掩膜用 `boundary.shp`。
5. 出图：`工程 → 新建打印布局`，加入地图、图例、比例尺、指北针。

## 3. 查看下载的原始数据

- `Copernicus_DEM_GLO30/raw/Copernicus_DSM_COG_10_N23_00_E102_00_DEM.tif`
  为 1°×1° 原始 GLO-30 瓦片（EPSG:4326，约 30 m），覆盖 102–103°E、23–24°N。
- `OpenStreetMap/raw/osm_yuanyang_core.geojson`
  可直接拖入 QGIS，按 `kind` 字段分类（road / waterway / building / forest / landuse）。

## 4. 常见问题

- **中文乱码**：QGIS 默认 UTF-8；若 dbf 属性乱码，在图层属性 → 源 → 数据源编码改为 `UTF-8`。
- **找不到 shp 的 prj**：每个 `.shp` 旁都有同名 `.prj`，不要只拷贝 `.shp`。
- **坐标系不一致**：本项目所有场景 GeoTIFF/Shapefile 均为 EPSG:32648（WGS84 / UTM 48N），
  网页与算法使用场景局部坐标（原点为西南角，x 向东、y 向北）。
