# 加榜梯田：先从这里开始

本包已按你新提供的研究方向改为**贵州加榜梯田、加车村附近初始实验框**。历史数据为2021—2025五个完整年份；实际获取日期为2026年11月10日。它用于历史分析与原型演示，不是当前实时天气或天气预报。

## 你先打开哪几个文件

1. `01_项目方向与C同学实施方案.md`：你作为C同学负责什么、怎样与地形和无人机模块衔接。
2. `加榜梯田气象数据_入门阅读版.xlsx`：中文字段、单位和1826天合并数据，先用它熟悉数据。
3. `02_整理后表格/J01_历史气象指标_非风险标签.csv`：已经计算好的3/7/14/30日累计降水等指标。
4. `03_空间范围/加榜初始框与背景点_坐标系待核准.geojson`：可导入GIS查看初始研究框，不能替代真实田块边界。

推荐第一项实验：**找出历史降雨较集中的时段 → 结合真实灌排与田埂资料提出巡检需求 → 用影像或现场记录核查**。没有核查证据时，只叫候选事件，不能叫已发生灾害。

## 研究区和空间精度

- 截图原始参考点：东经108.586886°、北纬25.602516°，背景请求点编号J01。
- 截图原始矩形：`[108.56, 25.58, 108.62, 25.625]`，顺序为西、南、东、北，约6.0×5.0公里。
- 截图提到高德地图，但未标明坐标系。本次保留原始数值，**暂按WGS84解释**取数，未进行未经确认的坐标转换。元数据明确标为`crs_verified=false`及`flight_ready=false`。真实田块、底图与飞行坐标仍待团队核准。
- NASA和ERA5仅使用一个区域背景点；相邻田块不能当作拥有不同的气象观测。
- ERA5接口实际返回网格中心：东经108.600006°、北纬25.599998°，服务返回网格高程779米；这不是现场测得的田块海拔。本次固定ERA5-Land模型并关闭接口的高程降尺度。
- CHIRPS标称分辨率0.05°，约数公里。服务导出数组为1826×2×2，但**每一天只有1个有效格点**，中心约东经108.5750043°、北纬25.6249996°。另外3格为服务的固定空间掩膜，不能填成零。
- CHIRPS的“初始框统计”是服务选中格点的算术均值；这次等于上述单个格点值，**不是完整矩形精确面积加权降水，也不是J01点位实测**。原始网格与坐标均已保留。

## 合并表字段字典

| CSV字段 | 中文含义与单位 |
|---|---|
| `date` | 日期；各来源仍保留各自日界线 |
| `nasa_tmean_c` / `nasa_tmax_c` / `nasa_tmin_c` | NASA日均/最高/最低气温，℃ |
| `nasa_rh_pct` | NASA日平均相对湿度，%（0—100） |
| `nasa_precip_mm_day` | NASA校正日降水，mm/day |
| `nasa_wind2m_ms` | NASA 2米平均风速，m/s，不是飞行高度风速 |
| `nasa_solar_mj_m2_day` | NASA地表向下短波辐射，MJ/m²/day；按本次API返回单位，不能误读为kWh |
| `era5_sm_0_7_m3_m3_daily_mean` | ERA5 0—7cm土壤体积含水率日均，m³/m³ |
| `era5_sm_7_28_m3_m3_daily_mean` | ERA5 7—28cm土壤体积含水率日均，m³/m³ |
| `era5_temperature_c_daily_mean` | ERA5 2米气温24小时算术平均，℃ |
| `chirps_selected_precip_mm_day` | CHIRPS服务选中格点日降水均值，mm/day，本次仅1格 |

NASA日数据为当地太阳时（LST）日，ERA5日均由北京时间每天24个小时值计算，CHIRPS按产品日期记录。合并表只是按日期并列，**没有统一三者的日界线**。不要直接把同日差值视为算法误差；事件对照时需要考虑时间窗口及空间覆盖差异。

缺测保留为空，不补零。ERA5某变量一天不足24个有效小时，就不输出该变量日均。本次核心变量无时间缺测，日期和小时序列连续、无重复。月汇总中，降水和辐射求和，其余列求平均；数据不全的月保留空值。

## 指标表怎样用

- `chirps_`与`nasa_`分别计算降水，不把不同来源相加。`rain_7d_mm`等为含当天在内的向后累计；前6天的7日指标为空是正常现象，30日指标同理。
- `consecutive_lt_threshold_days`为连续低于阈值的观测天数，`consecutive_ge_threshold_days`为连续达到阈值的天数。脚本默认1mm仅用于描述性“有雨/少雨日”划分，**不是经过验证的干旱、洪涝或病害阈值**。
- 连续天数从文件起点或最近缺测后重新计数，真实连续过程可能开始得更早；文件起点的连续天数属于已观测长度。
- `nasa_rh_7d_mean_pct`与`nasa_tmean_7d_mean_c`为7日均湿度和均温；`era5_sm_*_7d_mean_m3_m3`为7日平均土壤含水率。
- `change_vs_7days_ago_m3_m3`表示当天日均值减去7天前的日均值，不是两个周均值之差。
- 稻田正常蓄水不等于内涝，模式土壤水分不等于梯田水深，日均湿度不等于叶面湿润时长。指标的变化需要和作物生育期、灌排管理及核查证据一起解释。

## 如何复现

不写代码也可直接使用已生成的Excel和CSV。需要重新计算时，在数据包根目录打开终端，使用Python 3.10或以上：

```powershell
python -m pip install pandas numpy netCDF4
python "04_复现脚本/整理与核验.py"
python "04_复现脚本/计算历史气象指标.py"
```

原始数据已经下载好，无需再次联网。整理脚本重建CSV、GeoJSON和质量报告；指标脚本重建描述性指标。**这两个脚本不会自动刷新现有Excel阅读版或ZIP**，更新后应以CSV为准。

下载脚本仅依赖Python标准库。若需独立复现下载，可使用一个新目录，以避免与本次保存文件混淆：

```powershell
python "04_复现脚本/下载加榜原始数据.py" --output "加榜重新下载"
python "04_复现脚本/整理与核验.py" --output "加榜重新下载"
python "04_复现脚本/计算历史气象指标.py" --package "加榜重新下载"
```

服务限流或后台任务失效时可能需要重试；下载器会保留请求和任务记录。长期复现请优先保留本包原始文件及SHA256校验清单，因为外部服务或产品版本可能发生变化。
